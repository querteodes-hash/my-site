# Querteo

Личный сайт Querteo, фаундера и CEO. 3D-погружение: при скролле камера летит вглубь сцены, а секции вылетают из центра навстречу. С первого скролла горят долларовые купюры: чем глубже листаешь, тем больше сожжено. Имя QUERTEO разлетается на 3D-буквы и тоже сгорает.

## Что внутри

- **Three.js**: сцена, пост-обработка (bloom, хроматическая аберрация, зерно), стекло с преломлением.
- **Купюры $100**: текстуры лицевой стороны и оборота рисуются кодом (`src/banknote.js`), шейдер изгибает и мнёт бумагу, даёт рельеф краски, сдвиг синей защитной ленты и меди при наклоне, огонь с обугленной кромкой (`src/bills.js`).
- **Пачки денег**: 3D-модели с банковской лентой «$10,000» (`src/money.js`).
- **Lenis**: плавный скролл.
- **Шрифты** подключены локально: Unbounded, Playfair Display Italic, Martian Mono (с кириллицей). На купюрах Bodoni Moda.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:5173
npm run build    # сборка в dist/
```

## Деплой на Vercel

1. Зайти на [vercel.com/new](https://vercel.com/new) и импортировать репозиторий `querteodes-hash/my-site`.
2. Vercel сам определит Vite (настройки уже лежат в `vercel.json`): Build Command `npm run build`, Output Directory `dist`.
3. Нажать **Deploy**. Каждый пуш в ветку будет автоматически пересобирать сайт.
